# Vitra Max Vidros de Alto Padrão

Website oficial da **Vitra Max Vidros** — Especialista em Envidraçamento de Sacadas (Licenciada Balcony Brasil) e Portas Deslizantes para Grandes Vãos (Sistemas Roll Door).

## 🚀 Tecnologias e Recursos
- **HTML5 Semântico & CSS3 Responsivo Moderno:** Design de alto padrão inspirado na estrutura de alta conversão da Rebrace.
- **Autorizada Oficial:** Destaque para Balcony Brasil (NBR 16259) e Roll Door (linhas Slim, Robust e trilhos embutidos).
- **Sem Dependências Externas Frágeis:** Todas as imagens são locais (`imagens/`), garantindo carregamento ultrarrápido sem links quebrados de WordPress.
- **Seção Google Reviews Nativa:** Nota 5.0 estrelas com cabeçalho oficial do Google, badges de verificação e depoimentos reais.
- **Engenharia Náutica para o Litoral:** Destaques técnicos contra maresia, roldanas em aço inox 304/316 e testes de pressão de vento para edifícios altos.
- **Pronto para Deploy:** Configurado para cPanel (com `.htaccess` otimizado), Netlify (`netlify.toml`) e Vercel (`vercel.json`).
- **SEO & Indexação:** `sitemap.xml`, `robots.txt` e Schema.org (`LocalBusiness`, `HomeAndConstructionBusiness` e `FAQPage`).

## 📦 Deploy no cPanel / Hospedagem
1. Acesse o **Gerenciador de Arquivos** no cPanel da HostGator.
2. Abra a pasta `public_html/`.
3. Faça o upload do arquivo `E:\AntigravityProjetos\vitramax_cpanel_pronto.zip`.
4. Clique com o botão direito e selecione **Extract** (Extrair) diretamente na `public_html/`.
